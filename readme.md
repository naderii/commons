## 🤝 فرهنگ دانش مشترک

این پروژه بر این باور بنا شده است که دانش زمانی ارزشمندتر می‌شود که به اشتراک گذاشته شود و تجربه امروز، راهنمای فردای دیگران باشد.

ما به یادگیری جمعی، انتقال تجربه، مسئولیت‌پذیری و کمک به رشد یکدیگر باور داریم.

برای آشنایی با این فلسفه، منشور جامعه و روش‌های مشارکت، به فصل [فرهنگ دانش مشترک](docs/22-community-culture.md) مراجعه کنید.

## 🛠 اجرای محلی پروژه

```bash
pip install -r requirements.txt
mkdocs serve
```

برای ساخت نسخه نهایی:

```bash
mkdocs build
```

خروجی آماده انتشار در پوشه `site/` قرار می‌گیرد.
