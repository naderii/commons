    روش ۱: ریست دستی (GitHub / GitLab / VS Code)¶

    اگر این فایل را در GitHub یا GitLab باز کنی، می‌توانی تیک‌ها را بزنی. برای برداشتن همه تیک‌ها یک‌باره:

    1. روی آیکون ✏️ (Edit) بالای فایل بزن
    2. همه تیک‌ها را انتخاب کن (Ctrl+A)
    3. کلید Backspace یا Delete را بزن تا پاک شوند
    4. متن را دوباره از نسخه اصلی کپی کن

    بهترین راه (بدون کپی): یک فایل checklist-reset.md کنار این فایل بگذار با همین محتوا، و هر روز از آن کپی کن.
